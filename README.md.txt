# Valentine's Guardian

Valentine's Guardian is a small 2D pixel art action game prototype currently in development.

The game follows a pixel warrior who protects someone important to her in a small fantasy world.  
I am creating the character sprites, animations, backgrounds and gameplay code myself.

## Current Progress

- Created warrior idle animation
- Created second character(valentine) idle animation
- Started run animation experiments
- Started attack animation experiments
- Working on run animations
- Gameplay code is in progress
- Character movement system is being developed

## Planned Features

- Run animation
- Attack animation
- Jump animation
- Basic enemy system and enemy features
- Small playable level
- Custom pixel art backgrounds

## Tools Used

- Game Engine: Unity
- Programming: C#
- Art & Animation: Aseprite


## My Role
